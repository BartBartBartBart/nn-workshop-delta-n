# nn-workshop-delta-n
Train your own ML model with a hands-on MNIST workshop.

## Getting started

1. Clone this repository and open the project folder in VS Code:

	```bash
	git clone <repository-url>
	cd nn-workshop-delta-n
	code .
	```

2. Open [mnist_workshop.ipynb](mnist_workshop.ipynb).
3. Choose either a local Python environment or Google Colab, then follow the instructions in the notebook from top to bottom.
4. Run the cells in order and complete the `TODO` sections as you go.

The workshop introduces the steps involved in training and evaluating a convolutional neural network. No GPU is required.
